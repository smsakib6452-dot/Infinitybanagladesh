# Infinity Bangladesh Brand Assets Directory

Place the official brand assets in this directory:

- `infinity-logo.svg` (Primary official logo in SVG format)
- `infinity-logo.png` (Primary official logo in PNG format)
- `infinity-logo-white.svg` (Official logo for dark backgrounds)
- `infinity-favicon.png` (Official favicon)

When official logo files are not supplied, the website will display:
`[OFFICIAL INFINITY BANGLADESH LOGO REQUIRED]`
alongside the organization name: **Infinity Bangladesh** | **Team Infinity — United for Humanity**.
